# Deploy RH Madeplant - 2026-06-09

## Objetivo

Publicar a base atual do projeto no repositório GitHub `https://github.com/fozuna/rhmadeplant.git` e validar o pipeline local de release.

## Etapas executadas

1. Validacao do ambiente local
   - `php scripts/preflight.php`
   - Resultado: aprovado

2. Testes automatizados
   - `npm run test:unit`
   - Todos os testes PHP em `tests/php/*.php`
   - `npx playwright test tests/manual-ui.spec.js tests/public-vagas-guard.spec.js tests/admin-responsive.spec.js tests/share-menu.spec.js --project=chromium-desktop`
   - Resultado: aprovado

3. Ajustes para release
   - Inicializacao do repositório Git local em `main`
   - Configuracao do remote `origin`
   - Inclusao de `uploads/`, `dist/` e `storage/*.png` no `.gitignore`
   - Correcao do `deploy.ps1` para usar `npm.cmd` no Windows
   - Ajuste da view do manual para compatibilidade com o teste E2E de layout

4. Build e empacotamento
   - `php scripts/generate_build_info.php`
   - `powershell -ExecutionPolicy Bypass -File deploy.ps1`
   - Artefato gerado: `dist/rhmadeplant.zip`

## Observacoes

- O arquivo `app/config/build.php` e artefatos de runtime permanecem fora do versionamento conforme `.gitignore`.
- O fluxo `.cpanel.yml` ainda existe no projeto, mas o deploy desta entrega considera `GitHub apenas`.
